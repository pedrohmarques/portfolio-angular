# 🚀 Portfolio

Este é o meu portfólio pessoal, desenvolvido com **Angular 20**, com o objetivo de apresentar minha trajetória como desenvolvedor, minhas principais habilidades, projetos e experiência profissional.

## 📋 Sobre

No portfólio você encontrará:

* 👨‍💻 Informações sobre minha carreira e experiência profissional.
* 🛠️ Tecnologias e ferramentas que utilizo no desenvolvimento de software.
* 📂 Projetos desenvolvidos, com detalhes sobre arquitetura, tecnologias e funcionalidades.
* 📄 Meu currículo atualizado para visualização e download.
* 📬 Formas de entrar em contato.

## 🌐 Acesse

O portfólio está disponível em:

**https://pdhportfolio.netlify.app/**

## ⚙️ Tecnologias

* Angular 20
* TypeScript
* SCSS
* HTML5

## 📦 Executando o projeto

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Acesse a pasta do projeto:

```bash
cd <NOME_DO_PROJETO>
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
ng serve
```

Depois, acesse:

```
http://localhost:4200
```
